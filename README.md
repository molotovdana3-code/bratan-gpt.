# Братан GPT — ранний Android-прототип

Что уже есть:
- Android-интерфейс на Kotlin + Jetpack Compose.
- Распознавание русской речи средствами Android.
- Отправка текста на отдельный Node.js-сервер.
- Ответ от OpenAI API.
- Озвучивание ответа системным русским Text-to-Speech на телефоне.
- Несколько пресетов манеры общения (пока визуальные заготовки).

## Важно
Это исходный проект, не готовый APK. В среде создания нет Android SDK/Gradle, поэтому APK здесь не собран.
Приложение не подключается к подписке ChatGPT: для серверной части нужен отдельный OpenAI API key и оплата API по тарифам OpenAI.

## Запуск сервера
Требуется Node.js 20+.

```bash
cd server
npm install
# Linux/macOS:
export OPENAI_API_KEY="ваш_api_key"
npm start
```

Сервер слушает порт 3000. Не публикуйте его в интернет без HTTPS и авторизации.
Не вшивайте API-ключ в Android-приложение.

## Сборка Android
Откройте папку проекта в Android Studio (актуальная версия), дождитесь синхронизации Gradle и соберите:
Build -> Build Bundle(s) / APK(s) -> Build APK(s).

В поле «Адрес сервера» в приложении укажите адрес компьютера/сервера в вашей Wi-Fi сети, например `http://192.168.1.20:3000`.
`10.0.2.2` — адрес хоста только для Android Emulator, на реальном Samsung он не подойдёт.
